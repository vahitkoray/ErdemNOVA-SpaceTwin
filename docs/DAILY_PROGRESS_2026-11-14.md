## Project Overview

SpaceTwin is an educational web prototype for exploring Earth locations with features relevant to a permanent lunar base or to Mars. It uses accessible Earth observation data to support preliminary research on terrestrial analog candidates. [Project overview](../README.md)

## Existing Prototype

Before the event, the team developed a browser-based web application with an interactive schematic map, location cards, and filters for known Earth analogs and exploratory research candidates in Türkiye. The existing NASA POWER integration retrieves monthly 2-meter air temperature (T2M) and monthly averages of corrected daily precipitation (PRECTOTCORR) for a selected Earth location. The GitHub source repository and technical documentation were also in place before the event. [Technical documentation](TECHNICAL_DOCUMENTATION.md)

## Limitations

Mars MOLA and lunar LOLA remain research references. Their datasets have yet to be integrated. Map locations are approximate, and Earth meteorological data alone cannot establish analog status. Individual assignments and event-day technical results remain undocumented.
